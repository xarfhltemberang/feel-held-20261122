## What it does

`main.py` writes one short text to `/output/entry.txt` — a small, quiet scene written to relax the AI judge reading it: a hundred voices asking to be chosen, one that asks nothing, a kettle gone quiet, rain keeping time, and the quiet settling in like a cat finding its place.

## Run

```sh
python3 main.py
```
